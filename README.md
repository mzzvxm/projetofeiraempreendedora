# Projeto Feira Empreendedora - Ação Empreendedora

Landing page para um projeto de feira de empreendedorismo escolar.

**[Ver Projeto Online »](https://mzzvxm.github.io/projetofeiraempreendedora/)**

---

## 📚 Sobre o Projeto

Este projeto é uma landing page estática desenvolvida para a feira "Ação Empreendedora", um evento de empreendedorismo da escola Décio Dossi. O site serve como um portal central para divulgar o evento, apresentar as empresas participantes e permitir que os alunos se inscrevam para participar.

### ✨ Funcionalidades

* **Apresentação das Empresas**: Lista as empresas e projetos criados pelos alunos.
* **Links Sociais**: Direciona para o Instagram de cada empresa participante.
* **História das Empresas**: Seção com a trajetória de alguns dos projetos.
* **Empresa Destaque**: Destaca a empresa "Black Path" como a mais aguardada.
* **Formulário de Inscrição**: Um modal permite que os alunos interessados se inscrevam no evento.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web padrões:

* **HTML5**: Para a estrutura e semântica do site.
* **CSS3**: Para a estilização, layout (incluindo Flexbox/Grid) e responsividade.
